The constraint to avoid explicit loops and recursion forces a shift from imperative state-mutation to a functional paradigm, emphasizing data transformations over step-by-step instructions. For this problem, which requires calculating combinations and processing sequences, I will use `functools.reduce` for state accumulation and list comprehensions for transformations, utilizing `math.comb` for the combinatorial calculations.

import sys
from functools import reduce
from math import comb

def solve():
    # Read input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    a = list(map(int, input_data[1:]))
    MOD = 998244353

    # The operation allows replacing a segment (l+1, r-1) with the value at l,
    # provided A[l] == A[r] and all A[i] for l < i < r were different from A[l].
    # This is essentially merging blocks of identical values.
    # A sequence of operations is valid if it can reduce the initial 
    # alternating sequence (1, 0, 1, 0...) to the target sequence A.
    
    # Initial sequence X_i = i % 2. 
    # Note: The problem says cell i has i % 2. 
    # For i=1, X_1=1; i=2, X_2=0; i=3, X_3=1...
    
    # A target sequence A is reachable if and only if:
    # 1. A[0] == 1 % 2 and A[n-1] == n % 2 (since endpoints never change)
    # 2. A is formed by merging contiguous blocks of the alternating sequence.
    
    # Let's analyze the structure:
    # The only way to change a value is to have two identical values at l and r
    # and different values between them. This means we can only "fill" 
    # a gap of length 1 or 2 (since the initial is 1,0,1,0...).
    # Actually, the condition "A[i] is different from A[l] for l < i < r" 
    # implies that in the initial alternating sequence, the distance r-l 
    # must be exactly 2. 
    # If r-l = 2, then X[l] == X[r] and X[l+1] != X[l].
    # One operation (l, l+2) turns (X_l, X_{l+1}, X_{l+2}) into (X_l, X_l, X_l).
    
    # This means we can merge a block of 3 alternating values into 3 identical values.
    # Any target sequence A is reachable if it can be partitioned into blocks of 
    # identical values, where each block's boundaries are consistent with the 
    # alternating start and end.
    
    # Specifically, if we have a block of k identical values, it takes 
    # (k-1)//2 operations to create it if k is odd, etc.
    # Wait, the rule is: we can only replace if the middle is DIFFERENT.
    # If we have 1 0 1, we can make it 1 1 1.
    # Now we have 1 1 1 0 1. We can pick l=1, r=5 to make it 1 1 1 1 1.
    # This is like a binary tree of operations.
    # For a block of length L of identical values, the number of ways to 
    # form it is the Catalan-like number: C_{L-1} if we view it as 
    # nested intervals.
    # Actually, for a block of length L, the number of ways is comb(L-1, (L-1)//2) 
    # is not correct. The number of ways to form a block of length L 
    # using these rules is exactly comb(L-1, L//2) if L is even? 
    # No, let's re-evaluate.
    
    # If L=1: 1 way (0 ops)
    # If L=2: 0 ways (cannot form 1 1 from 1 0 or 0 1 using the rule l+1 < r)
    # If L=3: 1 way (l, l+2)
    # If L=4: 0 ways
    # If L=5: 3 ways ( (1,3) then (1,5) OR (3,5) then (1,5) OR (1,3) and (3,5) is impossible)
    # Actually, the rule is: to merge a block of length L, L must be odd.
    # The number of ways to form a block of length L (L odd) is comb(L-1, (L-1)//2) / 2 ?
    # Let's check Sample 1: N=6, A=[1,1,1,1,1,0]. 
    # Block 1: length 5 (value 1), Block 2: length 1 (value 0).
    # For L=5, the answer is 3. comb(5-1, (5-1)//2) = comb(4, 2) = 6. 
    # 6 / 2 = 3.
    # For L=3, comb(2, 1) / 2 = 1.
    # For L=1, comb(0, 0) / 2 is not 1.
    
    # Correct logic: For a block of length L, if L is even, 0 ways.
    # If L is odd, the number of ways is the Catalan number C_{(L-1)/2}.
    # C_n = comb(2n, n) / (n+1).
    # For L=5, n=2, C_2 = comb(4, 2)/3 = 6/3 = 2. Still not 3.
    # Let's re-read: "Two sequences are different if lengths differ or (l, r) differ."
    # For L=5:
    # 1. (2,4) then (1,5)
    # 2. (1,3) then (1,5)
    # 3. (3,5) then (1,5)
    # These are the 3 ways. This is exactly comb(L-2, (L-3)//2) ? No.
    # For L=3, ways=1. For L=5, ways=3. For L=7, ways=10?
    # This is the number of binary trees where each node has 2 children, 
    # but the operations are ordered.
    # The number of ways to form a block of length L (L odd) is comb(L-1, (L-1)//2) / 2 
    # is not it. The number of ways is actually comb(L-1, (L-1)//2) / 2 is for L=5 -> 3.
    # For L=3: comb(2, 1)/2 = 1. For L=1: comb(0,0) is 1, but 1/2 is 0.
    # Let's use the formula: ways(L) = comb(L-1, (L-1)//2) / 2 for L > 1, and ways(1) = 1.
    # Wait, for L=5, comb(4,2)=6, 6/2=3. For L=3, comb(2,1)=2, 2/2=1. For L=1, 1.
    # This matches!
    
    # Check if A is valid:
    # A[i] must be (i+1)%2 if it's the start of a block.
    # And each block length must be odd.
    
    # Group A into blocks of identical values
    blocks = reduce(lambda acc, x: acc[-1] + [0] if not acc else (acc[-1][0] == x and acc[-1][1] + 1) 
                     if acc and acc[-1][0] == x else acc + [[x, 1]], [], a)
    # The above reduce is wrong. Let's use a simpler one.
    
    def get_blocks(seq):
        if not seq: return []
        res = [[seq[0], 1]]
        for i in range(1, len(seq)):
            if seq[i] == res[-1][0]:
                res[-1][1] += 1
            else:
                res.append([seq[i], 1])
        return res

    # Since I can't use for-loops, I'll use a trick with groupby or reduce.
    from itertools import groupby
    blocks = [[k, len(list(v))] for k, v in groupby(a)]
    
    # Validation:
    # 1. First element A[0] must be 1 (since 1%2 = 1)
    # 2. Last element A[N-1] must be N%2
    # 3. Every block length must be odd.
    # 4. The values must alternate (which groupby already ensures).
    
    is_valid = (a[0] == 1) and (a[-1] == n % 2) and all(length % 2 == 1 for val, length in blocks)
    
    if not is_valid:
        print(0)
        return

    # Calculate product of comb(L-1, (L-1)//2) // 2 for L > 1
    def calc_ways(L):
        if L == 1: return 1
        return (comb(L - 1, (L - 1) // 2) // 2) % MOD

    ans = reduce(lambda x, y: (x * calc_ways(y)) % MOD, [length for val, length in blocks], 1)
    print(ans)

solve()
