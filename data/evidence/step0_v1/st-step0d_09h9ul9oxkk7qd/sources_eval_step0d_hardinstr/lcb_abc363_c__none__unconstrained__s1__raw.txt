The constraint to avoid explicit loops and recursion forces a shift from imperative programming to a functional style. This approach emphasizes "what" to compute rather than "how" to step through it, leveraging Python's powerful sequence processing tools. To solve this problem, I will use `itertools.permutations` to generate all possible arrangements of the string, `set` to handle duplicate permutations, and a list comprehension combined with `all()` to filter out strings containing palindromes of length $K$.

```python
import sys
from itertools import permutations

def solve():
    # Read input from standard input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    k = int(input_data[1])
    s = input_data[2]

    # Generate all unique permutations of the string S
    # Using a set to remove duplicates since S may have repeating characters
    all_perms = set([''.join(p) for p in permutations(s)])

    # A helper function to check if a string contains a palindrome of length K
    # We use a list comprehension to check every possible substring of length K
    # and all() to ensure none of them are equal to their reverse.
    # The condition is: for a string T, it is valid if for all i, T[i:i+k] != T[i:i+k][::-1]
    
    # We filter the set of permutations and count the survivors
    result = len([
        t for t in all_perms 
        if all(
            t[i : i + k] != t[i : i + k][::-1] 
            for i in range(n - k + 1)
        )
    ])

    # Print the final count
    sys.stdout.write(str(result) + '\n')

if __name__ == "__main__":
    solve()
```
