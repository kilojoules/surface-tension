The constraint to avoid explicit loops and recursion forces a shift toward a functional programming paradigm, emphasizing declarative data transformations over imperative state updates. In idiomatic Python, this encourages the use of high-level abstractions that operate on entire collections, often resulting in more concise code. To solve this problem without loops, I will use `sum()` for aggregate calculations, list comprehensions for data transformation, and `map()` for input processing.

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    
    N = data[0]
    # Extract Ls and Rs using slicing with steps
    # L values are at indices 1, 3, 5...
    # R values are at indices 2, 4, 6...
    L = data[1::2]
    R = data[2::2]
    
    sum_L = sum(L)
    sum_R = sum(R)
    
    # Condition for existence: 0 must be within [sum(L), sum(R)]
    # If sum_L > 0, the minimum possible sum is already > 0.
    # If sum_R < 0, the maximum possible sum is already < 0.
    is_possible = (sum_L <= 0 <= sum_R)
    
    # To find X_i, we start with X_i = L_i.
    # The current sum is sum_L. We need to add S = 0 - sum_L to the elements.
    # Each X_i can be increased by at most (R_i - L_i).
    # We distribute the required increase S across the elements.
    S = -sum_L
    
    # For each i, the amount we can add is min(S, R_i - L_i).
    # However, S changes as we iterate. Since we can't use loops,
    # we can use a prefix sum (via itertools.accumulate) to determine 
    # how much of the total deficit S is covered by the time we reach index i.
    
    # Let D_i = R_i - L_i. 
    # The amount added to X_i is min(D_i, S - (sum of D_j for j < i)).
    # This is equivalent to: 
    # X_i = L_i + max(0, min(D_i, S - prefix_sum_D_{i-1}))
    
    # Using a list comprehension to calculate D
    D = [R[i] - L[i] for i in range(N)]
    
    # We need the prefix sum of D to know how much "room" we had before index i
    # Since we can't use loops, we use a trick: 
    # The amount added to X_i is:
    # (PrefixSumD[i] - PrefixSumD[i-1]) if PrefixSumD[i-1] < S
    # (S - PrefixSumD[i-1]) if PrefixSumD[i-1] <= S <= PrefixSumD[i]
    # 0 if PrefixSumD[i-1] >= S
    
    # We can calculate the prefix sums of D using a list comprehension 
    # by summing slices, but that's O(N^2). 
    # Instead, we use the fact that we can use map/sum/etc.
    # Actually, we can just use the formula:
    # X_i = L_i + clamp(0, R_i - L_i, S - sum(D[0...i-1]))
    
    # To avoid O(N^2) and loops, we use a mathematical approach:
    # Let target = S.
    # We want to find the smallest k such that sum(D[0...k]) >= S.
    # For i < k: X_i = L_i + D_i = R_i
    # For i = k: X_i = L_i + (S - sum(D[0...k-1]))
    # For i > k: X_i = L_i
    
    # Since we can't use loops to find k, we can use a 
    # list comprehension to calculate the prefix sums 
    # if we use a helper that doesn't violate rules.
    # But wait, we can use `itertools.accumulate`!
    
    import itertools
    prefix_D = list(itertools.accumulate(D))
    
    # Now we can determine X_i based on the prefix sum.
    # X_i = L_i + (amount contributed to the sum S)
    # The contribution of index i is:
    # max(0, min(D[i], S - (prefix_D[i-1] if i > 0 else 0)))
    
    # We can build the result list in one go:
    res = [
        L[i] + max(0, min(D[i], S - (prefix_D[i-1] if i > 0 else 0)))
        for i in range(N)
    ]
    
    # Output result
    sys.stdout.write("Yes\n" + " ".join(map(str, res)) if is_possible else "No")

if __name__ == "__main__":
    main()
