**Wait**, I noticed a small logic error in the `bisect_left` threshold. 
If height $\ge H$, then $(current\_time - S) \ge H \implies S \le current\_time - H$.
So we want to count all $S$ in the range $[start\_idx, \text{last index where } S \le current\_time - H]$.
`bisect_right` with `current_time - H` will give the index of the first element $> current\_time - H$.
The number of elements is `bisect_right(...) - start_idx`.
