    # For each group, we iterate over all pairs of indices to find a difference d.
    # We only count the sequence if the current index is the start (index - d not in set).
    
    # Using a helper-like structure inside the comprehension:
    # For each group:
    #   For each pair (i, j) in group:
    #     d = j - i
    #     if (i - d) not in group_set:
    #       count = sum(1 for k in range(...) if (i + k*d) in group_set)
    
    res = max([
        max([
            sum(1 for k in range((n - 1) // d + 1) if (i + k*d) in group_set)
