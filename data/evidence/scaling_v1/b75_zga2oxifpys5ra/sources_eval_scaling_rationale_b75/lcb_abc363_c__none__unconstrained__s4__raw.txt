The constraint to avoid explicit loops and recursion forces a shift from imperative state management to a functional paradigm, emphasizing the use of higher-order functions and declarative data transformations. For this problem, which requires iterating through permutations and checking for palindromic substrings, I will use `itertools.permutations` to generate all possible arrangements, a list comprehension to filter those that do not contain a palindrome of length $K$, and a `set` to handle duplicate permutations caused by repeated characters in the input string. The palindrome check itself is implemented using slicing and comparison within a `any()` generator expression.

```python
import sys
from itertools import permutations

def solve():
    # Read N and K from the first line, and S from the second line
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    k = int(input_data[1])
    s = input_data[2]

    # Generate all unique permutations of the string S
    # We use a set of tuples because permutations() treats elements as unique by position
    all_perms = set(permutations(s))

    # Function to check if a permutation contains a palindrome of length K
    # A string T contains a palindrome of length K if there exists an i such that
    # T[i:i+k] == T[i:i+k][::-1]
    # We use a generator expression inside any() to check all possible substrings of length K
    is_palindrome_free = lambda p: not any(
        p[i : i + k] == p[i : i + k][::-1]
        for i in range(n - k + 1)
    )

    # Filter the permutations and count the ones that are palindrome-free
    # We use a list comprehension (or generator) passed to len() via a list conversion
    # or simply sum(1 for ...)
    result = sum(1 for p in all_perms if is_palindrome_free(p))

    # Print the final count
    print(result)

if __name__ == "__main__":
    solve()
```
