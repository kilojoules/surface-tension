The constraint to avoid explicit loops and recursion forces a shift from imperative programming to a functional style. While not necessarily "cleaner" for all developers, it encourages the use of high-level abstractions and built-in optimizations, leveraging Python's powerful sequence processing capabilities. For this specific problem (checking if the edit distance is $\le 1$), I will use slicing and generator expressions combined with `any()` and `all()` to validate the three possible operations (replacement, insertion, deletion) without using `for` or `while` loops.

```python
import sys

def solve():
    # Read input and handle potential trailing newlines
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    k = int(input_data[0])
    s = input_data[1]
    t = input_data[2]

    # Case 0: Strings are already identical
    if s == t:
        print("Yes")
        return

    # Since K=1, we only need to check if one operation suffices.
    # If the length difference is > 1, it's impossible.
    if abs(len(s) - len(t)) > 1:
        print("No")
        return

    # Helper to check if two strings are identical except for at most one position
    # Used for the 'Replace' operation (lengths must be equal)
    def check_replace():
        # Find indices where characters differ
        diffs = [i for i in range(len(s)) if s[i] != t[i]]
        return len(diffs) <= 1

    # Helper to check if removing one char from longer makes it the shorter
    # Used for 'Insert' and 'Delete' operations
    def check_single_diff(longer, shorter):
        # Find the first index where they differ
        # We use a generator expression with next() to find the first mismatch
        mismatch_idx = next((i for i in range(len(shorter)) if longer[i] != shorter[i]), len(shorter))
        # Check if skipping that character in the longer string makes them equal
        return longer[:mismatch_idx] + longer[mismatch_idx+1:] == shorter

    # Logic to determine if the transformation is possible
    # We use a conditional expression to map the length difference to the correct check
    result = (
        check_replace() if len(s) == len(t) else
        (check_single_diff(s, t) if len(s) > len(t) else 
         check_single_diff(t, s))
    )

    print("Yes" if result else "No")

if __name__ == "__main__":
    solve()
```
