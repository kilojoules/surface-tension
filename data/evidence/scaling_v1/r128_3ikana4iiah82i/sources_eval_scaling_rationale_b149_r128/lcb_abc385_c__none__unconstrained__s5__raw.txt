    # We can use a recursive-like structure via a trick or just

    # For every i and d, we check the sequence and stop at the first mismatch.
    
    # Since we can't use while, we can use a list comprehension to get the 
    # values at the intervals and then use a trick to count the prefix of identical values.
    
    # Let's refine:
    # For each i in 0..n-1:
    #   For each d in 1..n-1:
    #     Sequence S = [h[i + k*d] for k in range((n-1-i)//d + 1)]
    #     We need the length of the prefix of S that consists of h[i].
    
    # To count the prefix without a loop:

    # Or, more simply, since N is small (3000), we can just iterate

    # Wait, the condition is: "The chosen buildings are arranged at equal intervals."

    # Start reduce from i = n-1 down to 0

    # The answer is the maximum value in the DP table.

    print(max(final_dp.values()) if final_dp else (1 if n > 0 else 0))

    solve()
