The constraint to avoid explicit `for` and `while` loops forces a shift from imperative programming to a functional style. This encourages the use of declarative constructs that describe *what* the result should be rather than *how* to step through the process, leveraging Python's powerful comprehension syntax and built-in higher-order functions. To solve this problem, I will use nested list comprehensions to iterate over all possible starting positions and intervals, and `max()` to find the optimal result.

import sys

def solve():

    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    h = list(map(int, input_data[1:]))

    # 2. Are spaced at equal intervals.

    # Let d be the interval (1 to n-1)

    # have the same height as building i.
    
    # We use a generator expression inside max() to evaluate all combinations.

    # For a start index 'i' and interval 'd', we create a sequence of indices.
    # We count how many of those indices 'j' satisfy h[j] == h[i].
    # Note: The condition "equal intervals" implies we check indices i, i+d, i+2d...
    # and they must ALL have the same height to be part of the set.
    # Actually, the problem says "the chosen buildings are arranged at equal intervals".
    # This means if we pick indices (i, i+d, i+2d...), they must all have height H.
    
    # To maximize the count, for every pair of (i, d), we calculate the length of the 
    # sequence starting at i with step d that maintains the same height.
    
    # We use a helper function-like logic via list comprehensions.
    # For each i (start) and d (step), we find the maximum k such that 
    # h[i], h[i+d], ..., h[i+(k-1)*d] are all the same height.
    
    # However, a simpler approach:
    # For every i and d, we can determine the maximum k by checking the sequence.
    # Since we can't use while loops, we can use a list comprehension to find all

    # Wait, the condition "chosen buildings are arranged at equal intervals"

    # All these must have the same height.
    
    # Let's refine: for every i and d, we check the sequence i, i+d, i+2d...
    # and count how many consecutive elements starting from i have the same height.
    
    # Since we can't use while loops, we can use a trick with

    # Actually, the most straightforward way without loops:

    # Then we find the length of the prefix where all elements equal h[i].

    # We can use a list comprehension to find all indices where the height changes

    # Let's use a more direct approach:
    # For every i and d, we check all possible lengths k.
    # A length k is valid if for all m in 0...k-1, h[i + m*d] == h[i].
    
    # To avoid O(N^4), we can observe that for a fixed i and d,

    # Without loops or takewhile, we can use:
    # len([h[j] for j in range(i, n, d) if h[j] == h[i]]) 
    # ^ This is WRONG because it counts ALL matching heights, not just the 
    # consecutive ones at interval d. 
    # Wait, the problem says "the chosen buildings are arranged at equal intervals".
    # It does NOT say they must be consecutive in the sequence i, i+d, i+2d...
    # It says the set of chosen buildings must be {i, i+d, i+2d, ...}.
    # This means if we choose k buildings, they MUST be at indices i, i+d, ..., i+(k-1)d.
    # And all these must have the same height.
    
    # So for a fixed i and d, we want the largest k such that

    # We can calculate this by:
    # For each i and d, we look at the sequence S = h[i::d].
    # We want the length of the prefix of S consisting of identical elements.

    # We can use a generator to find the first index where S[j] != S[0].

    # But that's O(N^4). 
    
    # Let's use the property: 
    # For a fixed i and d, the maximum k is:
    # k = 1 + (length of the sequence of identical elements starting at 0)
    # We can find this by checking all possible k's and taking the max.

    # Optimized:
    # For every i and d, we can just check the sequence h[i::d].

    # We can use a list comprehension to find all indices where S[j] != S[0]

    #     S = h[i::d]
    #     diffs = [j for j, v in enumerate(S) if v != S[0]]

    ans = max(
        [

            )
            for i in range(n)
            for d in range(1, n)
        ] + [1] # Handle N=1 or default case
    )
    
    print(ans)
