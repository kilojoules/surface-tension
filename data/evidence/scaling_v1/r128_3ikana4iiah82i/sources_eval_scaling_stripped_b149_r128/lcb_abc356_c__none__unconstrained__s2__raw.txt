    # Check if a combination p is valid

        map(

            tests
        )
    )
    
    # Count valid combinations
    print(sum(map(lambda p: 1, filter(is_valid, product([0, 1], repeat=N)))))

Final check on the logic:
- `build_tests` recursively parses the input.
- `is_valid` checks if the combination `p` satisfies all `tests`.
- `sum(map(lambda p: 1, filter(is_valid, product(...))))` counts the valid ones.
- Time complexity: $O(2^N \cdot M \cdot N)$, which for $N=15, M=100$ is $\approx 32,768 \cdot 100 \cdot 15 \approx 49$ million operations. This should pass within time limits in Python if the operations are simple.
