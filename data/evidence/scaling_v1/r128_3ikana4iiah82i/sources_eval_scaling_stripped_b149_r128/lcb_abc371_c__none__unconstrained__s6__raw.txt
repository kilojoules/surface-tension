The cost is paid if we need to flip the edge in $H$ to match $G$. 
If $(i, j)$ is an edge in $G$, we need $(P_i, P_j)$ to be an edge in $H$. If it isn't, we pay $A_{P_i, P_j}$.
If $(i, j)$ is NOT an edge in $G$, we need $(P_i, P_j)$ to NOT be an edge in $H$. If it is, we pay $A_{P_i, P_j}$.

My code: `((i, j) in set_G) != (tuple(sorted((p[i-1], p[j-1]))) in set_H)` 
This correctly implements the XOR logic. If one is true and the other is false, the condition is true, and the cost is added.
