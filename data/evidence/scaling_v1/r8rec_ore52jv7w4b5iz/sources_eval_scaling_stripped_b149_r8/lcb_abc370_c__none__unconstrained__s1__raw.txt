Final check on the "lexicographically smallest array" requirement:
If we have two choices for the first string $X_1$:
1. Change $S[i]$ to $T[i]$ where $S[i] > T[i]$.
2. Change $S[j]$ to $T[j]$ where $S[j] < T[j]$.
Option 1 makes the string lexicographically smaller than $S$, Option 2 makes it larger. Thus, we always prefer Option 1. Among multiple $i$ where $S[i] > T[i]$, we pick the leftmost one to make the string as small as possible.
Once all $S[i] > T[i]$ are handled, we must handle $S[j] < T[j]$. To keep the string as small as possible, we change the rightmost $j$ first, as that preserves the smaller characters at the start of the string for longer.
