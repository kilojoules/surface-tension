import sys
from itertools import groupby

def solve():
    # Read input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    h = list(map(int, input_data[1:]))
    
    # Group indices by height: {height: [index1, index2, ...]}
    # We use a dictionary comprehension to organize indices of each unique height
    from collections import defaultdict
    height_groups = defaultdict(list)
    for idx, height in enumerate(h):
        height_groups[height].append(idx)
    
    # For each height group, we need to find the maximum number of indices 
    # that form an arithmetic progression.
    # Since N is small (3000), we can iterate through all pairs of indices (i, j)
    # within each height group to define a starting point and a common difference.
    
    # To avoid loops, we use a nested comprehension.
    # For a fixed height, we check every pair of indices (i, j) as the first two elements.
    # The common difference is d = j - i.
    # The number of elements isK = (last_index - i) // d + 1, 
    # provided the sequence is fully populated with that height.
    # However, the condition is "chosen buildings", meaning we can skip buildings.
    # Wait, the condition "arranged at equal intervals" means if we pick indices 
    # i, i+d, i+2d... they must all have the same height.
    
    # Let's refine: for every possible starting index 'i' and every possible 
    # interval 'd' (1 to N), count how many k satisfy H[i + k*d] == H[i].
    
    # We use a generator expression inside max()
    # We iterate d from 1 to N, and i from 0 to N-1.
    # For a fixed i and d, we count k such that i + k*d < N and H[i + k*d] == H[i].
    
    # To optimize: we only need to check d if there's at least one other building 
    # of the same height. If all heights are different, the answer is 1.
    
    # Using a list comprehension to evaluate all (i, d) pairs:
    # We use range(1, n) for d and range(n) for i.
    # For each (i, d), we use a while-like logic via a generator to count.
    # Since we can't use while, we can use a range and a filter.
    
    # The maximum possible k for a given i and d is (n - 1 - i) // d.
    # We check k in range((n - 1 - i) // d + 1).
    
    ans = max(
        (
            sum(1 for k in range((n - 1 - i) // d + 1) if h[i + k * d] == h[i])
            for i in range(n)
            for d in range(1, n)
        ),
        default=1
    )
    
    # The case for 1 building is covered by the range(0, 1) when k=0, 
    # but the constraints say N >= 1, so we handle it.
    # If N=1, the loops might result in 0 or 1. Let's ensure the minimum is 1.
    print(max(1, ans))

**Wait**, the logic above has a complexity of $O(N^3)$ because of the triple-nested structure (i, d, and the sum/range). With $N=3000$, $N^3$ is $27$ billion, which is too slow. I need a more efficient approach.

Correct approach: For each height, get the list of indices. For every pair of indices $(i, j)$ in that list, they define a potential interval $d = j - i$. We only need to check if $i, i+d, i+2d \dots$ have the same height. But actually, we can just iterate through all pairs of indices $(i, j)$ that have the same height and check the sequence. Even that is $O(N^3)$ in worst case (all heights same).

Actually, the constraint $N=3000$ and the "equal interval" rule suggests that for a fixed height $H$ and a fixed interval $d$, we can check all starting positions $i \in [0, d-1]$.

Let's use the property: for a fixed $d$, we can group indices by $(i \pmod d)$.
For a fixed $d \in [1, N]$ and a fixed height $h_{val} \in \text{unique(H)}$:
We want to find $i$ such that the count of $k$ where $H[i + kd] = h_{val}$ is maximized.

Actually, the simplest $O(N^2)$ is:
For every pair of indices $(i, j)$ with $H[i] == H[j]$, they define $d = j - i$. 
But we can't just count, because we need the indices to be *exactly* $d$ apart.
If we pick indices $i, i+d, i+2d \dots i+md$, they must all have height $H[i]$.

Correct $O(N^2)$ logic:
For each $d \in [1, N]$:
  Create a boolean array $B$ where $B[i] = 1$ if $H[i] == H[i-d]$ else $0$.
  This doesn't quite work because the height must be the same for the whole sequence.

Let's reconsider:
For each $d \in [1, N]$:
  For each $i \in [0, N-1]$:
    If $i \ge d$ and $H[i] == H[i-d]$, then $dp[i] = dp[i-d] + 1$.
    Else $dp[i] = 1$.
  The answer is $\max(dp)$.

This is $O(N^2)$.

```python
import sys

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    h = list(map(int, input_data[1:]))
    
    if n == 0:
        print(0)
        return

    # We want to find max(dp[i]) where dp[i] is the length of the 
    # equal-interval sequence ending at i with interval d.
    # Since we cannot use for-loops, we use a generator expression.
    # However, dp[i] depends on dp[i-d]. This is a recurrence.
    # We can solve this by iterating d from 1 to n, and for each d,
    # we can use a technique to simulate the DP.
    
    # For a fixed d, we can split the indices into d groups:
    # Group r: r, r+d, r+2d, ...
    # In each group, we look for the longest run of identical heights.
    
    # We can use itertools.groupby to find runs of identical heights.
    from itertools import groupby
    
    # For each d in [1, n], and each start r in [0, d-1]:
    # Extract the sequence H[r], H[r+d], H[r+2d]...
    # Find the longest run of identical elements using groupby.
    
    # To avoid loops, we use nested generator expressions.
    # The result is the maximum length of any group found.
    
    # We use a list comprehension to drive the 'd' and 'r' iterations.
    # We use a generator to extract the sequence and groupby to count runs.
    
    # Note: we must handle the case where n=1 separately or ensure range(1, n) 
    # doesn't swallow the result. The minimum answer is 1.
    
    res = max(
        (
            max(
                (
                    len(list(group)) 
                    for key, group in groupby(
                        (h[i] for i in range(r, n, d))
                    )
                ),
                default=0
            )
            for d in range(1, n)
            for r in range(d)
        ),
        default=1
    )
    
    # The case for d=0 is not possible, and d=n is redundant.
    # If n=1, the range(1, n) is empty, so default=1 handles it.
    # We also need to consider the case where we just pick one building.
    print(max(1, res))

if __name__ == "__main__":
    solve()
```
Wait, the logic `groupby((h[i] for i in range(r, n, d)))` finds the longest **contiguous** run of identical heights in the sampled sequence. This is exactly what "equal intervals" and "same height" means. If the sampled sequence is `[5, 7, 5, 7, 7]`, the runs are `[5], [7], [5], [7, 7]`, and the max length is 2. This is correct.

Final check on complexity:
$\sum_{d=1}^{N} \sum_{r=0}^{d-1} \frac{N}{d} = \sum_{d=1}^{N} N = N^2$.
With $N=3000$, $N^2 = 9,000,000$, which fits within the time limit for Python.

from itertools import groupby

def solve():
    # Read all input at once
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    # N is the first element, H is the rest
    n = int(input_data[0])
    h = list(map(int, input_data[1:]))
    
    if n == 0:
        print(0)
        return

    # We iterate through all possible intervals d from 1 to n-1.
    # For each d, we check all possible starting positions r from 0 to d-1.
    # For each (d, r), we create a sequence of heights at that interval.
    # groupby identifies contiguous blocks of the same height.
    # We find the length of the longest block.
    
    # Using a generator expression to find the maximum length.
    # The outermost max handles the overall result.
    # The middle max handles the best run for a specific (d, r).
    # The innermost len(list(group)) calculates the run length.
    
    result = max(
        (
            max(
                (
                    len(list(group)) 
                    for key, group in groupby(
                        (h[i] for i in range(r, n, d))
                    )
                ),
                default=0
            )
            for d in range(1, n)
            for r in range(d)
        ),
        default=1
    )
    
    # Ensure the minimum answer is 1 as per problem statement.
    print(max(1, result))

if __name__ == "__main__":
    solve()
