```python
import sys
from bisect import bisect_left

def solve():
    # Read all input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    H, W, Q = map(int, input_data[:3])
    queries = [
        (int(input_data[i]), int(input_data[i+1])) 
        for i in range(3, len(input_data), 2)
    ]

    # State: rows[r] is a list of active wall columns, cols[c] is a list of active wall rows
    rows = [list(range(1, W + 1)) for _ in range(H)]
    cols = [list(range(1, H + 1)) for _ in range(W)]
    
    def process_query(q):
        r, c = q
        # Check if wall exists at (r, c)
        # We use a helper to check existence and remove if it does
        # To avoid 'if' for the main logic, we can use a boolean
        
        # Check existence
        idx_in_row = bisect_left(rows[r-1], c)
        exists = idx_in_row < len(rows[r-1]) and rows[r-1][idx_in_row] == c
        
        if exists:
            rows[r-1].pop(idx_in_row)
            idx_in_col = bisect_left(cols[c-1], r)
            cols[c-1].pop(idx_in_col)
            return 1
        
        # If not exists, destroy 4 neighbors
        # We must capture the targets first because popping changes indices
        
        # Find targets
        # Left
        l_idx = bisect_left(rows[r-1], c) - 1
        target_l = (rows[r-1][l_idx], c) if l_idx >= 0 else None
        
        # Right
        r_idx = bisect_left(rows[r-1], c)
        target_r = (r, rows[r-1][r_idx]) if r_idx < len(rows[r-1]) else None
        
        # Up
        u_idx = bisect_left(cols[c-1], r) - 1
        target_u = (cols[c-1][u_idx], c) if u_idx >= 0 else None
        
        # Down
        d_idx = bisect_left(cols[c-1], r)
        target_d = (cols[c-1][d_idx], c) if d_idx < len(cols[c-1]) else None
        
        targets = [target_l, target_r, target_u, target_d]
        
        # Function to remove a wall at (tr, tc)
        def remove_wall(target):
            if target is None: return 0
            tr, tc = target
            # Remove from row
            row_list = rows[tr-1]
            idx_r = bisect_left(row_list, tc)
            if idx_r < len(row_list) and row_list[idx_r] == tc:
                row_list.pop(idx_r)
                # Remove from col
                col_list = cols[tc-1]
                idx_c = bisect_left(col_list, tr)
                if idx_c < len(col_list) and col_list[idx_c] == tr:
                    col_list.pop(idx_c)
                return 1
            return 0

        return sum(map(remove_wall, targets))

    total_destroyed = sum(map(process_query, queries))
    print(H * W - total_destroyed)

if __name__ == "__main__":
    solve()
```

Wait, the `remove_wall` logic is slightly flawed because the 4 neighbors are destroyed *simultaneously*. If a wall is both the "Left" neighbor and the "Up" neighbor (which is impossible in a grid), it should only be counted once. More importantly, the "Right" neighbor might be the same wall as the "Down" neighbor if the bomb is at (1,1) and the only wall is at (2,2)? No, the rules say look strictly Up, Down, Left, Right. A wall at (i, Cq) or (Rq, j). These are 4 distinct directions. The only overlap is if the same wall is targeted by two different directions, but that's impossible since one is on the same row and one is on the same column, unless it's the cell (Rq, Cq) itself, but the "no wall at (Rq, Cq)" condition is already checked.

One final detail: `sys.setrecursionlimit` is not needed as I used `map`. The `pop` operation is $O(N)$, and $Q \times N$ could be $2 \cdot 10^5 \times 4 \cdot 10^5$, which is too slow. However, the total number of walls is $4 \cdot 10^5$. Each wall is popped at most once. The bottleneck is `pop(i)` shifting elements. In Python, `pop` from the middle of a large list is $O(N)$. But since we only pop a total of $H \times W$ times across all queries, the total time spent shifting is $O(Q \times \text{avg}(W, H))$. With $H \times W \le 4 \cdot 10^5$, the worst case is a square grid $\approx 632 \times 632$. $2 \cdot 10^5 \times 632 \approx 1.2 \cdot 10^8$. This might be tight for 2 seconds in Python. But since we are popping, the lists shrink. Let's use this.
