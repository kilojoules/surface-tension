Actually, the logic `(sx + (sy % 2)) // 2` is slightly off for the "even" rule.
Rule: "When $i+j$ is even, $A_{i,j}$ and $A_{i+1,j}$ are in the same tile."
If $j$ is even, $i$ must be even for $i+j$ to be even. So $A_{0,j}$ and $A_{1,j}$ are one tile.
If $j$ is odd, $i$ must be odd for $i+j$ to be even. So $A_{1,j}$ and $A_{2,j}$ are one tile.
This means for $j$ even, tiles are $[0,1], [2,3] \dots$ (index $i // 2$)
For $j$ odd, tiles are $[-1,0], [1,2], [3,4] \dots$ (index $(i+1) // 2$)
This matches `(sx + (sy % 2)) // 2`.

Final check:
$j=0$ (even): $x=0 \to 0, x=1 \to 0, x=2 \to 1, x=3 \to 1$. Formula: $(x+0)//2$. Correct.
$j=1$ (odd): $x=0 \to 0, x=1 \to 1, x=2 \to 1, x=3 \to 2$. Formula: $(x+1)//2$. Correct.
(Note: $x=0$ at $j=1$ is in a tile with $x=-1$).
