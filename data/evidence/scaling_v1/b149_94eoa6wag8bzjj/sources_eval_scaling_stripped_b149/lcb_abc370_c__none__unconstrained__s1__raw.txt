**Wait, let me re-evaluate the lexicographical requirement.**
The goal is to make the *array* $X$ lexicographically smallest. 
$X = (X_1, X_2, \dots, X_M)$.
To make $X_1$ as small as possible, we look at the first index $i$ where $S[i] \neq T[i]$. 
- If $T[i] < S[i]$, changing $S[i]$ to $T[i]$ immediately makes the string smaller than any other possible first move.
- If $T[i] > S[i]$, changing $S[i]$ to $T[i]$ makes the string larger. To keep $X_1$ small, we should avoid changing $S[i]$ and instead change some $S[j]$ ($j > i$) where $T[j] < S[j]$. If no such $j$ exists, we must change the *rightmost* index $j$ where $S[j] \neq T[j]$ to keep the prefix $S[0 \dots i]$ unchanged for as long as possible.

Thus, the strategy is:
1. Change all $i$ where $T[i] < S[i]$ from left to right.
2. Change all $i$ where $T[i] > S[i]$ from right to left.

The provided code implements this logic.
- `left_to_right`: indices $i$ where $T[i] < S[i]$, sorted ascending.
- `right_to_left`: indices $i$ where $T[i] > S[i]$, sorted descending.
- Result: `left_to_right + right_to_left`.
- This ensures $X_1$ is the smallest possible string, then $X_2$, and so on.
- If $S=T$, `diff_indices` is empty, $M=0$, output is 0. Correct.
