**Wait**, I used a list comprehension `[int(next(it)) for _ in range(N)]` and `solve_recursive`. The prompt says "no for/while loops". List comprehensions are technically loops. Let me refine this to be strictly functional.

Corrected approach: Use `map` and `next` inside a recursive function, and `slice` or `itertools.islice` to get $N$ elements.

```python
import sys
from itertools import islice

# Increase recursion depth for T = 10^5
sys.setrecursionlimit(300000)

def solve():
    # Read all input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    it = iter(input_data)
    T_val = int(next(it))
    
    def process(t):
        if t <= 0:
            return []
        
        # Get N
        n_str = next(it)
        n = int(n_str)
        
        # Get P using islice to avoid list comprehensions
        p = list(map(int, islice(it, n)))
        
        # Check if sorted: all(P[i] == i + 1)
        # We use map and all to avoid loops
        is_sorted = all(map(lambda x: x[0] == x[1] + 1, enumerate(p)))
        
        # Check if any P[i] == i + 1
        has_fixed = any(map(lambda x: x[0] == x[1] + 1, enumerate(p)))
        # Wait, the logic above is slightly wrong. 
        # enumerate(p) gives (index, value). 
        # We need value == index + 1.
        
        # Corrected checks:
        # is_sorted: for all i, p[i] == i + 1
        # has_fixed: exists i, p[i] == i + 1
        
        # Let's redefine checks clearly:
        # check_sorted = all(p[i] == i + 1 for i in range(n)) -> range is allowed? 
        # The prompt says no for/while. Range in all() is a generator expression.
        # To be safe, I'll use map and enumerate.
        
        # Re-evaluating:
        # is_sorted: all(val == idx + 1 for idx, val in enumerate(p))
        # has_fixed: any(val == idx + 1 for idx, val in enumerate(p))
        
        # Using map/lambda to be strictly "no loop"
        check_fixed = lambda pair: pair[1] == pair[0] + 1
        
        res_is_sorted = all(map(check_fixed, enumerate(p)))
        res_has_fixed = any(map(check_fixed, enumerate(p)))
        
        ans = 0 if res_is_sorted else (1 if res_has_fixed else 2)
        
        return [ans] + process(t - 1)

    # Using a helper to call process and print
    # We use sys.stdout.write to avoid print() in a loop
    sys.stdout.write('\n'.join(map(str, process(T_val))) + '\n')

if __name__ == "__main__":
    solve()
```

Final check on logic:
- If $P$ is sorted $\rightarrow 0$.
- If $P$ is not sorted, but there is some $k$ such that $P_k = k$, then sorting $[1, k-1]$ and $[k+1, N]$ will result in $(1, \dots, k-1, k, k+1, \dots, N) \rightarrow 1$.
- Otherwise $\rightarrow 2$.
This is correct.
