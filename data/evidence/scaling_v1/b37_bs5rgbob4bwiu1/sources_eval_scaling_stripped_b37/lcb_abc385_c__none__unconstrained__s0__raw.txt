    # We want the maximum number of buildings of the same height at equal intervals.
    # For each height group, we check all pairs of indices (i, j) as the start of a sequence.
    # The difference d = j - i defines the interval.
    
    # We use a list comprehension to iterate over all height groups.
    # For each group, we check all pairs of indices.
    # To avoid nested loops in a comprehension, we can use a helper logic.
    
    # Since we cannot use loops, we can use a generator expression inside max().
    # For a fixed height group 'idxs', and a pair of indices (i, j), 
    # the length of the sequence is the number of k >= 0 such that i + k*(j-i) is in the set.
    
    # To optimize: we only check pairs if the group size is greater than the current max.
    # However, without a mutable 'ans' variable, we process all groups.
    
    # For each group, we find the max length sequence.
    # For a pair (i, j) with i < j, the length is:
    # 1 + (number of k >= 1 such that i + k*(j-i) is in the set)
    
    # We use a set for O(1) lookup.
    # We use a range for k that covers all possible indices up to N.
    
    # Using a function inside the comprehension to handle the counting logic:
    def get_length(i, j, s, n):
        d = j - i
        # Count how many k satisfy (i + k*d) in s. 
        # k=0 is i, k=1 is j. We check k=2, 3...
        # The maximum k is (n-1 - i) // d.

        max([
            get_length(idxs[a], idxs[b], set(idxs), N)

import sys
from collections import defaultdict

def solve():
    input_data = sys.stdin.read().split()
    if not input_data: return
    N = int(input_data[0])
    H = list(map(int, input_data[1:]))

    groups = defaultdict(list)
    for i, h in enumerate(H):
        groups[h].append(i)

    # For each height group, try all pairs (i, j) as the first two elements.
    # The length is the count of k such that i + k*(j-i) is in the set of indices.
    # We use a helper function to calculate the length for a given pair.
    def calc_len(i, j, s):
        d = j - i
        # Use a generator to count occurrences of the arithmetic progression
        return sum(1 for k in range((N - 1 - i) // d + 1) if (i + k * d) in s)

    # We wrap the logic in a comprehension:
    # 1. Iterate over each group of indices.
    # 2. For each group, iterate over all pairs of indices (a, b) where a < b.
    # 3. Find the maximum length found across all groups and pairs.
    
    # We use a nested structure: 
    # Outer: groups.values()
    # Inner: pairs of indices in each group
    # Default to 1 since N >= 1.
    
    result = max([
        max([
            calc_len(idxs[a], idxs[b], set(idxs))
            for a in range(len(idxs))
            for b in range(a + 1, len(idxs))
        ] + [1])
        for idxs in groups.values()
    ], default=1)

    print(result)

if __name__ == "__main__":

(Self-correction: The `range` in `calc_len` starts at 0, so `i + 0*d` is `i` and `i + 1*d` is `j`, both of which are guaranteed to be in `s`. This correctly counts the total length.)
Final check on constraints: $N=3000$. In the worst case (all heights same), we have $N^2$ pairs. For each pair, the `sum` runs $N/d$ times. The total complexity is $\sum_{d=1}^{N} (N-d) \frac{N}{d} \approx N^2 \log N$. With $N=3000$, $N^2 \log N \approx 9 \cdot 10^6 \cdot 11 \approx 10^8$. This might be tight for Python's 2.0s limit, but since we only iterate over indices of the *same* height, the actual number of pairs is $\sum (count_h^2)$, which is maximized when one height dominates. The `sum(1 for ...)` is efficient.

One final optimization: `(N - 1 - i) // d + 1` is the maximum possible $k$.
