        def distribute(remaining):
            for L, R in pairs:
                # Calculate how much we can add to the current L
                add = min(remaining, R - L)
                yield L + add

            def update(self, delta):

Final logic:
1. Calculate `min_sum` ($\sum L_i$) and `max_sum` ($\sum R_i$).
2. If $0 < min\_sum$ or $0 > max\_sum$, output `No`.
3. Otherwise, output `Yes`.
4. To find $X_i$, start with $X_i = L_i$. The deficit is $0 - \sum L_i$.
5. Distribute the deficit across $X_i$ by adding $\min(\text{remaining deficit}, R_i - L_i)$ to each $X_i$. This is achieved using a list comprehension and a helper class to maintain the state of the remaining deficit.
6. Print the resulting sequence.
7. Time Complexity: $O(N)$, Space Complexity: $O(N)$.
8. Constraints: $N=2 \cdot 10^5$, values up to $10^9$. Python handles large integers automatically.
