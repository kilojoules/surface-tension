def solve():
    # Read N and Q
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    N = int(input_data[0])
    Q = int(input_data[1])
    
    instructions = []
    idx = 2
    for _ in range(Q):
        h = input_data[idx]
        t = int(input_data[idx+1])
        instructions.append((h, t))
        idx += 2

    # State: (left_hand, right_hand)
    # We want to find the minimum operations to reach the final state.
    # Since N and Q are small (100), and we only move one hand at a time,
    # the state space is N*N. We can use DP.
    # dp[i][l][r] = min operations after instruction i with hands at (l, r)
    
    # Initial state: L=1, R=2
    # We use a dictionary to store current reachable states: {(l, r): min_ops}
    current_states = {(1, 2): 0}

    # Function to calculate shortest distance between two points on a ring of size N
    # without passing through a forbidden point 'obstacle'.
    # Since we can move in two directions (clockwise and counter-clockwise),
    # we check both paths.
    def get_dist(start, end, obstacle, n):
        # Path 1: Increasing index (1 -> 2 -> ... -> N -> 1)
        # Path 2: Decreasing index (1 -> N -> ... -> 2 -> 1)
        
        # To simplify, we can use a helper to check if a path is blocked
        def is_blocked(s, e, obs, direction):
            # direction 1: clockwise, -1: counter-clockwise
            curr = s
            while curr != e:
                # Move curr in direction
                curr = (curr + direction - 1) % n + 1
                if curr == obs:
                    return True
            return False

        # Clockwise distance
        dist_cw = (end - start + n) % n
        # Counter-clockwise distance
        dist_ccw = (start - end + n) % n
        
        # Check if paths are blocked by the obstacle
        # A path is blocked if the obstacle lies strictly between start and end
        # For clockwise: start < obstacle < end (with wrap around)
        # Easier: check if the obstacle is encountered while stepping
        
        blocked_cw = is_blocked(start, end, obstacle, 1)
        blocked_ccw = is_blocked(start, end, obstacle, -1)
        
        res = float('inf')
        if not blocked_cw:
            res = min(res, dist_cw)
        if not blocked_ccw:
            res = min(res, dist_ccw)
        return res

    for h, t in instructions:
        next_states = {}
        for (l, r), cost in current_states.items():
            if h == 'L':
                # Move left hand from l to t, right hand r stays fixed
                d = get_dist(l, t, r, N)
                if d != float('inf'):
                    new_state = (t, r)
                    next_states[new_state] = min(next_states.get(new_state, float('inf')), cost + d)
            else:
                # Move right hand from r to t, left hand l stays fixed
                d = get_dist(r, t, l, N)
                if d != float('inf'):
                    new_state = (l, t)
                    next_states[new_state] = min(next_states.get(new_state, float('inf')), cost + d)
        current_states = next_states

    print(min(current_states.values()))

**Wait**, I noticed a logic error in my `is_blocked` function. The problem says "you can do this only if the other hand is not on the destination part." This means the obstacle cannot be the *destination* of a single step. My `is_blocked` checks if the obstacle is hit *during* the transition. However, the prompt guarantees that $T_i \neq r_i$ when $H_i$ is $L$, so the destination itself is never the obstacle. The only thing that matters is if the obstacle blocks the path *between* the current position and the target.

Let's refine the distance logic: on a ring, there are only two paths between any two points. If the obstacle is at position $X$, it blocks one of the two arcs unless $X$ is the start or end point. Since the obstacle is the *other* hand, and we are told the other hand doesn't move, the obstacle is stationary.

Correct logic for `get_dist(start, end, obstacle, N)`:
1. Clockwise distance: `(end - start) % N`. This path is blocked if the `obstacle` is encountered.
2. Counter-clockwise distance: `(start - end) % N`. This path is blocked if the `obstacle` is encountered.

A point $X$ is on the clockwise path from $S$ to $E$ if we encounter $X$ while incrementing $S$ modulo $N$ until we hit $E$.
